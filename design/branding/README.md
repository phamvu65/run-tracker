# RunTracker icon

- `runtracker-logo-pink.png`: pink logo edited with built-in imagegen.
- `runtracker-icon-vector-preview.png`: preview of the Android vector silhouette.
- App source: `app/src/main/res/drawable/ic_launcher_foreground.xml` and `ic_launcher_background.xml`.
- Pink `#FF5CA8`, background `#0D0D12`. The foreground has transparent cutouts and safe-area padding; existing adaptive launcher and round launcher resources use it for normal and monochrome themed icons. Minimum Android API is 26.
- The vector is a simplified trace of the generated logo for crisp rendering. The app UI palette is unchanged.

Imagegen edit prompt:
> Edit this RunTracker app logo. Preserve the exact R route shape, circular endpoints, proportions and centered placement. Change all green symbol areas to vivid pink #FF5CA8. Make the background perfectly flat solid near-black #0D0D12. Clean flat colors, crisp edges, remove glow/texture. No new elements, no text. Same square composition and generous margins. This will be the actual Android app launcher icon.
